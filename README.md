## Getting Started

### Prerequisites
- Node.js 18+
- MongoDB instance (if backend features are used locally)

### Installation

```bash
git clone https://github.com/Pvekariya/KAPIS_LIGHTS.git
cd KAPIS_LIGHTS
npm install
```

### Environment Variables

```
MONGODB_URI=your_mongodb_connection_string
[any other required env vars — form submission API keys, etc.]
```

### Run Locally

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).
